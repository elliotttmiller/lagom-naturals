# Theme tokens

## Compact summary

- Framework: React 19 + Vite; CSS is vanilla layered imports.
- Primary product-card treatment: white/light photography over a dark charcoal, translucent glass information shelf.
- Card: 3:4 desktop aspect ratio, 24px radius, clipped overflow.
- Shelf: charcoal `rgba(26,30,25,.78)`, 18px backdrop blur, diagonal top via clip path.
- Type: project `--font-ui` / `--font-primary`; product name is high contrast white inside glass shelf.
